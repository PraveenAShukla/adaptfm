# Contributing

This is a competition writeup. The parts we would most like help with are the open
questions in [docs/future-work.md](docs/future-work.md), none of which we have measured
properly.

**Useful:** telling us one of them is already answered, with the reference. Telling us a
number looks wrong — several rest on our own logs from a competition run under time
pressure. Reproducing something on different hardware; ours are one A10G's numbers and we
would not assume they transfer.

If you want to work on one of the open questions, open an issue first so we do not
duplicate.

**The standard.** Everything here should be a number we measured with its conditions, a
number from the official results, or an open question — and marked as which. A pull
request reporting a speedup should say what hardware, what prompt shapes, how many runs,
and what the quality check was.

No model weights, no container archives, no credentials or private host names, including
in logs. If you add a result, add the command that produced it.
